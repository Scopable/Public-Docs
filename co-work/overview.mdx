Co-Work is Scopable's AI assistant — a conversational workspace where you can ask questions, run analyses, and take actions using your actual client data. Whether you're preparing for a QBR, reviewing a compliance posture, or drafting a quote strategy, Co-Work works alongside you with the full context of your client environment already loaded.

## How Co-Work Is Different

Unlike a general-purpose AI chatbot, Co-Work has direct access to your connected client records, PSA data, RMM configurations, and Microsoft environment information. You don't need to copy and paste data into a chat window — Co-Work reads it from your integrations in real time.

## Key Concepts

<Accordion title="Conversations">
  A **conversation** is a persistent chat session with Co-Work. You can start as many as you need, run them in parallel, and return to any past conversation to pick up where you left off. Each conversation maintains its own context and history.
</Accordion>

<Accordion title="Skills">
  **Skills** are focused instruction sets that give Co-Work additional capabilities or constraints. A guidance skill might tell Co-Work to always use NIST framework terminology; an action skill might connect Co-Work to an integration so it can pull or push live data. You control which skills are active per conversation.
</Accordion>

<Accordion title="Background Runs">
  When Co-Work is working on a long task — such as analyzing a large dataset or running a multi-step workflow — you can navigate to another client or a different page in Scopable. The run continues in the background. A status indicator in the Co-Work panel shows you when the task finishes.
</Accordion>

## Where to Find Co-Work

Click the **Co-Work icon** in the left navigation bar to open the Co-Work panel. The panel is available from any page in Scopable — you don't need to leave your current context to start a conversation.

<Note>
  Co-Work uses the data from your connected integrations. The more integrations you connect, the richer the context Co-Work has when helping you. Connect your PSA, RMM, and Microsoft environment in **Settings → Integrations** to get the most out of Co-Work.
</Note>
