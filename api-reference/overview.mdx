The Scopable API is a versioned REST surface — base URL `https://api.scopable.io`, all routes under `/v1` — that lets any external system, script, or automation tool read and write your CRM data without touching the Scopable UI. Every request authenticates with a Bearer API key, every list endpoint uses cursor pagination, and every write requires an idempotency key so retries are always safe.

## What you can do today

The current API surface covers your core client and contact data:

**Clients**

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/v1/clients` | List all clients with cursor pagination |
| `GET` | `/v1/clients/{clientId}` | Get a single client by ID |
| `POST` | `/v1/clients/{clientId}` | Update a client's fields |

**Contacts**

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/v1/contacts/search` | Search contacts by name or email, optionally scoped to a client |
| `POST` | `/v1/contacts` | Create a new contact |
| `POST` | `/v1/contacts/{contactId}` | Update a contact's fields |
| `POST` | `/v1/contacts/{contactId}/archive` | Archive a contact |
| `POST` | `/v1/contacts/{contactId}/restore` | Restore an archived contact |
| `POST` | `/v1/contacts/{contactId}/set-default` | Make a contact the client's default |

**Webhooks**

- **Outbound HMAC-signed webhooks** — subscribe to `client.updated` and `contact.*` event notifications delivered to your endpoint whenever client or contact data changes

## What's not yet available

The following features are managed exclusively in the Scopable UI today and are not yet exposed through the API:

- Opportunities and CPQ quotes
- Assessments and GRC compliance records
- Bulk import or export

## Quick start

Make your first API call in under a minute. Replace `$SCOPABLE_API_KEY` with a key generated in **Settings → Developer** (see [Authentication](/api-reference/authentication) for the full walkthrough).

```bash
curl -s "https://api.scopable.io/v1/clients?limit=1" \
  -H "Authorization: Bearer $SCOPABLE_API_KEY"
```

A successful response returns a `data` array containing your first client record and a `nextCursor` value you can use to page forward.

## OpenAPI document

The live OpenAPI specification is always available at **[https://scopable.io/openapi.json](https://scopable.io/openapi.json)** and reflects the current API surface. Import it into Postman, Insomnia, or any OpenAPI-compatible toolchain to generate a client or explore endpoints interactively.

<Note>
  The OpenAPI document is updated automatically whenever new endpoints or fields are added. Pin to specific schema versions in your CI pipeline by snapshotting the file rather than fetching it at build time.
</Note>
