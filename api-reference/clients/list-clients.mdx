The List Clients endpoint returns every client record your API key has access to in your Scopable tenant. Results are ordered by creation date and delivered in pages — use the `nextCursor` value from each response to fetch the next page. This endpoint requires the `clients:read` scope.

## Endpoint

```http
GET https://api.scopable.io/v1/clients
```

## Query Parameters

<ParamField query="limit" type="integer" default={50}>
  Number of clients to return per page. Must be between `1` and `200`. Defaults to `50`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor returned as `nextCursor` in a previous response. Omit this parameter to start from the first page.
</ParamField>

## Example Request

```bash
curl "https://api.scopable.io/v1/clients?limit=25" \
  -H "Authorization: Bearer $SCOPABLE_API_KEY"
```

## Pagination

Pass the `nextCursor` value from one response as the `cursor` parameter on your next request to advance through pages. When `nextCursor` is `null`, you have retrieved all clients.

```bash
# Fetch the second page using the cursor from the first response
curl "https://api.scopable.io/v1/clients?limit=25&cursor=eyJ2IjoxfQ" \
  -H "Authorization: Bearer $SCOPABLE_API_KEY"
```

<Note>
  Clients cannot be created or archived through the API. Client records originate from your connected PSA (ConnectWise Manage or Halo PSA) or are created directly inside the Scopable app.
</Note>
