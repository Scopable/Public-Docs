---

The Get Client endpoint fetches a single client record by its Scopable UUID. Use this endpoint when you already have a `clientId` — for example, from a webhook payload or a previous list response — and need the complete, up-to-date client object. This endpoint requires the `clients:read` scope.

## Endpoint

```
GET https://api.scopable.io/v1/clients/{clientId}
```

## Path Parameters

<ParamField path="clientId" type="string" required>
  The UUID of the client to fetch. Must belong to your Scopable tenant.
</ParamField>

## Example Request

```bash
curl "https://api.scopable.io/v1/clients/3f0c2a4e-8d1b-4c6a-9e2f-5b7d1a0c9e84" \
  -H "Authorization: Bearer $SCOPABLE_API_KEY"
```

## Error Responses

<Note>
  If a `clientId` belongs to a different tenant, Scopable returns `404 not_found` — not `403 forbidden`. This prevents your integration from inferring whether a given UUID exists in another tenant.
</Note>

| HTTP Status | Error Code | Meaning |
|---|---|---|
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `forbidden` | Your API key does not have the `clients:read` scope. |
| `404` | `not_found` | No client with that ID exists in your tenant. |
| `429` | `rate_limited` | You have exceeded 600 read requests per minute. |
| `503` | `unavailable` | Scopable is temporarily unavailable — retry with backoff. |
