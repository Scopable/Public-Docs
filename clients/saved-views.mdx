Saved Views let you preserve your preferred search, filter, column, sort, and page-size settings on any client-detail table. Instead of reconfiguring the same filters every time you open a table, you save the configuration once and return to it instantly — or set it as your default so it loads automatically.

## Which Tables Support Saved Views

Saved Views are available on the following tables inside a client record:

- **Contacts**
- **Agreements**
- **Configurations / Assets** (where applicable)
- **Compliance framework tables** (GRC module)

## How to Save a View

<Steps>
  <Step title="Configure the table">
    Set the columns, filters, sort order, and page size exactly how you want them.
  </Step>
  <Step title="Click Save View">
    Click the **Save View** button in the table toolbar (top-right area of the table).
  </Step>
  <Step title="Name the view">
    Type a descriptive name — for example, *Active agreements by renewal* or *Primary contacts only* — then click **Save**.
  </Step>
</Steps>

The view appears in the **Views** dropdown immediately and is available to you on future visits.

## Setting a View as Your Default

1. Open the **Views** dropdown in the table toolbar.
2. Hover over the view you want to make default.
3. Click **Set as Default**.

The next time you open that table, it loads with your default view applied automatically — no manual filtering required.

## Sharing a View

By default, Saved Views are personal — only you can see them. To make a view available to everyone on your Scopable account:

1. Open the **Views** dropdown.
2. Hover over the view you want to share.
3. Click **Share**.

Scopable makes the view account-wide. All users see the shared view in their own Views dropdown, but they can still override it with their own settings without affecting the shared version.

<Note>
  Saved Views are per-table and per-user by default. Sharing a view makes it account-wide and visible to all active users. Shared views can be used but not edited by non-owners; only the view's creator or an Admin can rename or delete a shared view.
</Note>

## Editing or Deleting a View

1. Open the **Views** dropdown.
2. Click **Manage Views**.
3. Find the view you want to update, then:
   - Click **Rename** to change its name.
   - Click **Delete** to remove it permanently.

Deleting a view that is another user's default resets their table to the unfiltered state the next time they open it.

<Tip>
  Create a shared default view for your team's most common configuration — for example, Contacts filtered to active records sorted by last name. This ensures everyone on the account starts from the same consistent baseline.
</Tip>
